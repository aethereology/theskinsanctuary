# claude.md

## Executive summary

Build a static-first, mobile-first website for The Skin Sanctuary Co that prioritizes booking conversion, local clarity, and trust. The design reference is warm neutral luxury with deeply readable typography, minimal navigation, and constant booking access.

The site should feel polished but personal. Use Monica Talbot’s warmth, detail orientation, and relaxing studio environment as the emotional center of the copy and UI.

## Source of truth

Use this order of truth:
1. User-supplied Square screenshot for service names, prices, durations, and visible descriptions
2. User-supplied Google Business Profile excerpt for address, hours, review count, rating, and review quotes
3. Public Linktree and booking/social links for service taxonomy and live offer confirmation
4. User-supplied image assets

Do **not** invent product brands.
Do **not** fill in the partially cut-off waxing item.
Do **not** publish an exact Welcome Facial duration until confirmed.

## Recommended implementation model

- Static site or hybrid-rendered site is ideal
- No CMS required for v1
- Store business data in a single JSON or TS config object
- Reuse data to populate service tables, hours, contact, schema, and metadata
- Keep booking flow external through Square

## Outbound tracking helper

```js
function trackOutboundClick(label, destination) {
  if (window.gtag) {
    window.gtag('event', 'outbound_click', {
      event_category: 'engagement',
      event_label: label,
      destination
    });
  }
}

document.addEventListener('click', (event) => {
  const link = event.target.closest('[data-track]');
  if (!link) return;
  trackOutboundClick(link.dataset.track, link.getAttribute('href') || '');
});
```
